# superdator-inference client

Webcam client for the superdator-inference server.

## Install

```
pip install "git+https://github.com/GustavPetterssonBjorklund/superdator-inference.git#subdirectory=client"
```

## Run

Clone the repo (or just grab `main.py`) and run:

```
python main.py --url ws://<server-host>:8000/stream
```

Press `q` to quit.
